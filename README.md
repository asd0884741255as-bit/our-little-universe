# เว็บครบรอบอัยย์ & ทัก

เปิดด้วยการรัน `python -m http.server 8765 --bind 127.0.0.1 --directory _anniversary_analysis/website` จากโฟลเดอร์ love แล้วเข้า http://127.0.0.1:8765

เว็บไซต์นี้เป็นฉบับดูในเครื่อง ยังไม่ได้เผยแพร่ รายการรูปคัดจากฐานที่เจ้าของอนุญาต PUBLIC_WEB_OK เท่านั้น ภาพส่วนลับไม่ได้รวมอยู่ใน assets และห้องแมวดำเป็นมินิเกม ไม่ใช่ระบบเก็บภาพส่วนตัว

ความทรงจำแสดงตามข้อความที่เจ้าของยืนยัน ส่วนวันที่บางรายการอ้างอิง metadata เดิม วันเริ่มคบคือ 6 กันยายน 2024 และครบรอบสองปีคือ 6 กันยายน 2026

รูปที่ใช้เป็นสำเนา preview ใน assets ไม่ได้แก้ไขรูปต้นฉบับ ฟอนต์โหลดจาก Google Fonts โดยมีฟอนต์ไทยสำรองหากออฟไลน์ รายการโปรดและหัวใจเก็บในเบราว์เซอร์เครื่องนี้

การจัดหน้าเว็บรวมเหตุการณ์ที่เจ้าของยืนยันว่าเป็นเรื่องเดียวกันไว้ในการ์ดเดียว: พาใจกลับบ้าน (Homecoming) รวมรูป P022, P023, P024, P076; ไปเจอพ่อแม่ครั้งแรก รวม P013, P054–P056; วันตัดผมรวม P066, P074; ทริปกาญจนบุรีรวม P001, P008; งานโชว์สัตว์น้ำที่เซ็นทรัลเวิลด์รวม P002, P026; และเซลฟี่จากโทรศัพท์ทักรวม P070, P071. เหตุการณ์ “นักล่าหมูกระทะ” และรูป P025 ถูกนำออกจากเว็บตามคำขอ โดยไฟล์ต้นฉบับยังอยู่ครบ

วิดีโอที่เจ้าของอนุญาตจะแสดงเป็นวิดีโอจริงใน Timeline, Gallery และ Viewer โดยเริ่มเล่นอัตโนมัติแบบปิดเสียง เล่นในหน้าเดิม และวนซ้ำเมื่อจบ สามารถใช้แถบควบคุมใน Viewer เพื่อหยุดหรือเลื่อนได้ ไฟล์ที่นำมาใช้เป็นสำเนาใน assets เท่านั้น
