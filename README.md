# เว็บครบรอบอัยย์ & ทัก — Our Little Universe

เปิดใช้งานในเครื่องด้วยการรัน:

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory .
```

จากโฟลเดอร์ `our-little-universe` แล้วเข้า `http://127.0.0.1:8765`

## ขอบเขตข้อมูลและความเป็นส่วนตัว
- เว็บไซต์นี้คัดกรองรายการรูปและวิดีโอจากฐานที่เจ้าของอนุญาต `PUBLIC_WEB_OK` เท่านั้น ภาพส่วนลับไม่ได้รวมอยู่ใน `assets/` และห้องแมวดำเป็นมินิเกม ไม่ใช่ระบบเก็บภาพส่วนตัว
- ความทรงจำแสดงตามข้อความที่เจ้าของยืนยัน ส่วนวันที่บางรายการอ้างอิง metadata เดิม วันเริ่มคบคือ **6 กันยายน 2024** และครบรอบสองปีคือ **6 กันยายน 2026**
- การจัดหน้าเว็บรวมเหตุการณ์ที่เจ้าของยืนยันว่าเป็นเรื่องเดียวกันไว้ในการ์ดเดียว:
  - พาใจกลับบ้าน (Homecoming) รวมรูป `P022`, `P023`, `P024`, `P076`
  - ไปเจอพ่อแม่ครั้งแรก รวม `P013`, `P054–P056`
  - วันตัดผมรวม `P066`, `P074`
  - ทริปกาญจนบุรีรวม `P001`, `P008`
  - งานโชว์สัตว์น้ำที่เซ็นทรัลเวิลด์รวม `P002`, `P026`
  - เซลฟี่จากโทรศัพท์ทักรวม `P070`, `P071`
- เหตุการณ์ “นักล่าหมูกระทะ” และรูป `P025` ถูกนำออกจากเว็บตามคำขอ

## ฟีเจอร์หลักที่พัฒนาเพิ่มเติม
1. **Visual & Typography (Warm Editorial Scrapbook + Starry Night Mode):**
   - จับคู่ฟอนต์ไทยไร้หัว (`Anuphan`) สำหรับหัวข้อ และฟอนต์ไทยมีหัว (`Noto Sans Thai`) สำหรับเนื้อหา เพื่อให้อ่านง่ายและไม่เกิดปัญหาวรรณยุกต์ซ้อนทับ
   - เพิ่มปุ่มสลับโหมดกระดาษกลางวัน (`☀`) และโหมดดูดาวกลางคืน (`☾ Starry Night Mode`)
2. **Real-Time Relationship Counter:**
   - แสดงทั้งจำนวนวันครบรอบสองปี (`730 วัน`) และนาฬิกานับเวลาแบบวินาทีต่อวินาที (ปี / เดือน / วัน / ชั่วโมง / นาที / วินาที) นับจากวันที่ `06.09.2024`
3. **Search, Sort & Enhanced Media Viewer:**
   - ค้นหาความทรงจำแบบทันที กรองตามปี (`2024`, `2025`, `2026`, `ไม่ระบุวันที่`) หรือกรองเฉพาะคลิปวิดีโอ (`🎬 คลิปวิดีโอ`) และรายการโปรด (`♡ ที่เก็บไว้`)
   - หน้าต่าง Viewer รองรับปุ่มลูกศรซ้าย-ขวา คีย์บอร์ด (`ArrowLeft`/`ArrowRight`/`Escape`) การปัดนิ้วบนมือถือ (Touch Swipe) แถบภาพย่อ (Thumbnail Strip) และโหมดเล่นสไลด์โชว์อัตโนมัติ (`▷ เล่นสไลด์โชว์`)
4. **4 Interactive Mini-Games & Upgraded Black Cat Room:**
   - **01 / QUIZ:** ทายใจอัยย์และเหตุการณ์สำคัญ (8 คำถามจากข้อมูลจริง)
   - **02 / MEMORY MATCH:** จับคู่ภาพความทรงจำพร้อมนับจำนวนครั้งที่พลิกการ์ด
   - **03 / ZOOM OUT:** ค่อย ๆ ซูมออกแล้วทายชื่อเหตุการณ์จากตัวเลือก
   - **04 / TIMELINE SORT:** เรียงลำดับ 4 เหตุการณ์จริงตามเส้นเวลาจากเกิดก่อนไปเกิดทีหลัง
   - **ห้องแมวดำ (Black Cat Room):** ระบบเลเวลความผูกพัน ของเล่น 3 แบบ (ขนมปลา, ไหมพรม, เกาคางกล่อมนอน) และตู้เสื้อผ้าเครื่องประดับแมวดำ (ดอกทานตะวัน, โบสีชมพู, มงกุฎ, ดาวนำโชค) ที่ซิงก์แสดงผลบนมาสคอตมุมจอ
5. **สมุดโน้ต & คำอธิษฐานปีที่ 3 (Couple's Wish Jar):**
   - เขียนบันทึกความในใจหรือสิ่งที่อยากทำด้วยกันต่อ เก็บไว้ในเบราว์เซอร์ (`localStorage`) และดาวน์โหลดเก็บเป็นไฟล์การ์ดข้อความ (`.txt`) ได้
